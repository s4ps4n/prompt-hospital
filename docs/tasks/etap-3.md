# Этап 3: персонажи-чиби + статусы + визуальная система

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).
Прочитай перед работой:
1. `docs/handoff/README.md` — разделы «Персонаж (чиби)», «Визуальная система», «Анимации».
2. `src/journal/types.ts`, `src/journal/catalog.ts` — готовые типы и каталог моделей (этап 1).

## Что сделать

Реализовать **спрайты персонажей** (SVG) и **визуальную систему статусов**. Ты работаешь
только в каталоге `src/characters/` и `src/theme/` — НЕ трогай `src/scene/` (там параллельно
работает другой исполнитель) и `src/journal/` (уже принято).

## Персонаж (чиби) — по README

- Голова r=17 (~50% роста), белые глаза + зрачки, брови, рот по статусу, румянец, ухо.
- Причёски из каталога: `style` = cap | bob | quiff | spiky | bun.
- Аксессуары: `acc` = wings | glasses | headset.
- Сидит за столом (3/4 к зрителю), руки на клавиатуре, ЭЛТ-монитор сбоку экраном к зрителю.
- Данные из `CATALOG`: `hair`, `color` (одежда), `skin`, `style`, `acc`.

## Требования

- Всё — чистые SVG-компоненты (React), без внешних библиотек.
- Персонаж принимает `worker` + `catalogEntry`, возвращает SVG-группу.
- Палитра и контуры — из `src/theme/` (создай `src/theme/colors.ts`, если ещё нет; согласуй
  константу контура `#241a0c` с этапом 2 — не дублируй магическими числами).
- Типы строгие, без `any`.

## Проверки качества (от координатора)

- **Контраст:** текст вывески (имя/роль) на фоне `#f7d23a` должен быть читаем — проверь
  контраст тёмного текста `#241a0c` / `#6a4a10` на `#f7d23a` (минимум 4.5:1 для текста).
- Все 5 причёсок и 3 аксессуара отрисовываются различимо, не «сливаются».
- Статус читается по экрану И лампочке без подписи.
