# Fix: кофе/прогулка — стоящая поза, как у дизайнера (продолжение issue #2)

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).

## Проблема

В `src/animations/IdleDirector.tsx` для поз `coffee` и `walk` рисуется `sprite` —
это **сидячий** `Character` (без стула, `furniture={false}`). Поэтому персонаж пьёт
кофе/гуляет без туловища и ног — «голова и руки».

У дизайнера это **стоящий персонаж**: в референсе есть отдельная функция `standing()`.

## Источник истины

`docs/handoff/Office Orchestrator.dc.html`, функция `standing()` (строки ~378–391) и
`character()` (строки ~333–377). Открой/прочитай их и перенеси логику точно.

Ключевое из `standing()`:
- `character(cat, st, anim, seed, 'stand')` — тело **без головы** (при `stand` анимации
  головы нет), туловище рисуется (`c.body.slice(1)` — тень отбрасывается).
- **Ноги** (`leg()`): два прямоугольника + эллипсы-ступни, при walk анимируются `stepA/stepB`.
- **Руки**: walk → `stepA/stepB`; coffee → `cupArm` (рука с чашкой + пар `steam`).
- Сборка: тень → ноги → `translate(0,-15)` на группе (тело + руки).

## Что сделать

Реализовать **стоящую позу** для idle (`walk`, `coffee`) по референсу:
- персонаж стоит: ноги, туловище, голова (статичная), руки;
- walk — шаги (ноги и руки), coffee — рука с чашкой + пар;
- `sleep` остаётся сидячей позой (голова на столе), как уже исправлено.

## Требования

- Сверяй координаты с `standing()` в референсе, не изобретай.
- Обнови тесты (стоящая поза: есть ноги и туловище; кофе — рука с чашкой).
- `npm run build`, `npx vitest run`, `npm run lint` — зелёные.
