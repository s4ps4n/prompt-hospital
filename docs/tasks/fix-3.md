# Fix: разнообразие idle-поз + доработка походки (issue #2, владелец)

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).

## 1. Разнообразие idle (баг: все делают одно и то же)

В `src/animations/schedule.ts` функция `idleOffset(id)` даёт почти одинаковый сдвиг
для последовательных id (`w1`, `w2`, …): хэш `(hash*31+ch) % N` почти не различает
id, различающиеся последней цифрой. Поэтому все бездельники в один момент времени в
одной позе — все гуляют, или все пьют кофе, или все спят.

**Сделай:** равномерный хэш id (FNV-1a или аналог), чтобы сдвиг в цикле `walk/coffee/sleep`
различался между моделями, и бездельники делали **разное** одновременно.

Сверься с референсом: в README дизайнера «Бездельники по своему графику (~45 с на занятие,
со сдвигом по id)». Требование — позы разнесены по моделям, а не синхронны.

## 2. Походка (владелец: «что за походка?»)

Сверь walk-анимацию с референсом дизайнера `docs/handoff/Office Orchestrator.dc.html`
(`walkLane`, `face`, `stepA/stepB`, `bob`). Найди, что делает походку нелепой, и исправь.

Возможные причины (проверь все):
- персонаж «скользит» (walkLane плавно двигает, а ноги только топают `translateY` — нет
  переступания);
- разворот `face` (scaleX) дёргает персонажа (timing `steps`);
- фазы ног не противофазны (обе ноги вверх одновременно — «прыгает»);
- путь (`lane.from/to`) задаёт странную траекторию (не по коридору);
- единицы пути (`px` в CSS-переменных) не совпадают с SVG-координатами при масштабе.

Сделай походку естественной, в духе референса (мелкие шаги + плавное перемещение по коридору).
