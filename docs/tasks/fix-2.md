# Fix: визуальные дефекты idle — сверка с референсом дизайнера (issue #2)

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).

## Источник истины

`docs/handoff/Office Orchestrator.dc.html` — референс дизайнера. Внутри функция
`character()` (в `<script data-dc-script>` / `support.js`) показывает, как дизайнер
рисует позы и анимации. **Сверяйся с ней, не изобретай геометрию.**

## Что исправить

### 1. Голова в позе «сон» не должна поворачиваться
Сейчас в `src/theme/animations.css:44`:
```css
.ph-idle-sleep .ph-head { transform: translate(-22px,44px) rotate(-65deg); }
```
Это самодеятельность — у дизайнера голова в сне ОСТАЁТСЯ на месте.
У дизайнера «сон» = закрытые глаза (дуги) + приоткрытый рот (см. строку про
`sleep?h('g',{key:'eyes'},...дуги...)` в character()). «z z z» и слюна — поверх, как уже есть.

**Сделай:** убери rotate/translate головы. Сон рисуется закрытыми глазами (дуги) и
соответствующим ртом, голова на месте. «z z z» + drool остаются.

### 2. Кофе — у двери комнаты (не на глаз)
Сейчас позиция кофе — константа `door` «на глаз». У дизайнера дверь выводится из
геометрии комнаты (L=160, коридор G=110, шаг 270, поле M=55). Найди в `src/scene/`
реальную геометрию комнаты и вычисли позицию двери из неё, а не хардкодом.

### 3. Маршрут прогулки — по коридору перед комнатой, в пределах поля M=55
Сверь с геометрией сцены, чтобы гуляющий оставался в коридоре перед своей комнатой.

## Требования

- Сверяй координаты с референсом дизайнера и с `src/scene/` (геометрия комнат).
- Обнови тесты (sleep без поворота головы, кофе у двери, маршрут в коридоре).
- `npm run build`, `npx vitest run`, `npm run lint` — зелёные.
