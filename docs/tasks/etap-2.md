# Этап 2: изометрическая сцена

2. `src/journal/` — готовый слой журнала (этап 1): `types.ts`, `selectors.ts`, `initial.ts`, `catalog.ts`.

## Что сделать

Реализовать **изометрическую сцену офиса** — React-компонент, который отрисовывает
раскладку комнат из состояния журнала. Персонажей на этом этапе НЕТ (они — этап 3),
но комнаты, пол, стены, коридор, зона отдыха и сетка — уже да.

## Точные параметры (из README дизайнера, не менять)

- Изометрия 2:1: `P(x,y,z) = [x − y, (x + y)/2 − z]`.
- Комната L=160, коридор G=110, шаг 270, поле M=55, высота стен H=64, толщина T=6.
- Кабинет Гермеса `2L+G` (ячейки 0..1 × 0..1).
- Сетка колонок C=4 (prop `cols`). Остальные заполняют построчно; при переполнении — новый ряд.
- Пустые ячейки ряда — зона отдыха (скамья, кулер, растения) с кнопкой «＋ свободная комната».
- Painter's algorithm: порядок отрисовки по сумме координат центра `ox + oy + S`.
- Масштаб: вписать в контейнер, но не меньше 0.55; вывески/конверты контр-масштабируются до ×1.5.

## Визуальная система (палитра и грани — строго по README)

- Контур всех объектов `#241a0c`, 2px, round joins.
- Грани коробок: верх = цвет, левая (+y) ×0.84, правая (+x) ×0.68.
- Ковры по ролям: координатор `#cf5d5d`, исполнитель `#e89b98`, архитектор `#a99ae0`,
  фулстак `#88b4ea`, сисадмин `#8fd0a0`, дизайнер `#f0c07a`, UX/UI `#e6a2d2`, приёмщик `#c9b98e`.
- Панель стены — цвет ковра ×0.8/0.9.
- Стены `#f3ead2`, верх `#d9c79c`; внешние стены — кирпич `#b5623a`/шов `#e2b48a`;
  пол коридора — шахматка `#d3d3de`/`#babbcc`; трава — полосы `#4dae3e`/`#44a236`.

## Требования

- Компонент чистый: принимает `journal` + `cols`, возвращает SVG. Нет внутреннего состояния DOM.
- Раскладка считается из `journal.workers` (динамическая — добавление модели растягивает офис).
- Типы строгие, без `any`. Тесты на геометрию (координаты проекции, painter-порядок, сетку).
- Палитра вынести в отдельный модуль (`src/theme/colors.ts`), чтобы этап 3 и 7 переиспользовали.

## Проверки качества (от координатора)

- Проекция изометрии проверяется тестом (точка (0,0,0), (1,0,0), (0,1,0), z-сдвиг).
- Painter's algorithm: задние комнаты рисуются раньше передних — тест на порядок.
- Контраст текста на коврах (вывески будут на этапе 3, но фон ковра уже сейчас должен
  давать читаемый белый/тёмный текст — проверь, что ни один ковёр не «сливается» с контуром).
