# Этап 6: интеграция — персонажи в сцену, приоритизация, полёт конверта

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).
Прочитай: `docs/handoff/README.md` (разделы «Раскладка», «Анимации», «Drag-and-drop»),
`src/characters/README.md`, `src/animations/` (IdleDirector из этапа 5).

Теперь можешь трогать: `src/scene/`, `src/app/`, `src/ui/`, `src/animations/`, `src/theme/`,
`src/characters/`. `src/journal/` не трогай (принято).

## Задачи (по порядку)

### 6.1 Персонажи в painter-порядке (критично)

Сейчас персонажи рисуются отдельным слоем ПОВЕРХ сцены. Это неправильно: они должны
рисоваться внутри комнаты по painter's algorithm — за передней стенкой, вперемешку с мебелью.
- Дай комнате (`src/scene/Room.tsx`) **слот для содержимого** (children или render-prop),
  чтобы содержимое попадало в painter-порядок комнаты.
- Подключи `Character` + `Workstation` + `WorkerSign` внутрь комнат через этот слот.

### 6.2 Idle-анимации

Подключи `IdleDirector` (из `src/animations/`) к персонажам: бездельники (wait/done, кроме
Гермеса) гуляют / пьют кофе / спят по детерминированному графику. `motion=false` отключает.

### 6.3 Полёт конверта

После drop конверт летит в цель 450 мс (left `cubic-bezier(.4,0,.2,1)`, top
`cubic-bezier(.3,-.6,.6,1)` — дуга), операция применяется **по приземлении**, а не сразу.

### 6.4 Приоритизация в UI

Убедись, что в лотке и очередях: флажки приоритета (высокий `#e0402e`, средний `#f2c230`,
низкий `#a3a3a3`), сортировка `priority desc, order asc`, reorder перетаскиванием работает.

### 6.5 Чистка

- Вычисти стили Vite из `src/index.css` (оставь только базовый reset, всё специфичное — в `app/`).
- Перенеси `UI_EXTRA` из `src/ui/styles.ts` в `src/theme/colors.ts` (единый источник палитры).

## Требования

- Отрисовка — чистая функция от журнала. Интеграция не должна ломать этапы 1–5.
- Тесты: персонаж в комнате попадает в painter-порядок (за передней стенкой); idle-поза
  по графику; полёт конверта откладывает операцию до приземления; приоритетная сортировка.
- `npm run build` зелёный, `npx vitest run` зелёный, `npm run lint` 0 ошибок.
