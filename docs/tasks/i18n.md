# i18n интерфейса: русский + английский

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).

## Цель

Все подписи и статусы интерфейса офиса сейчас захардкожены по-русски. Нужно вынести их в
словарь и добавить переключатель языка RU/EN.

## Что сделать

1. **Таблица переводов для людей** — `src/i18n/translations.csv`:
   первая строка — `key,ru,en`, дальше по строке на ключ. Это источник, который ведут
   люди в Excel / Google Sheets. Новый язык = добавить столбец (например `de`) — и он
   «подтянется» везде автоматически. Собери туда ВСЕ строки, которые видит пользователь:
   - верхняя панель: название, «＋ Модель», зум, «Журнал», «Сброс», переключатель языка;
   - карточка модели: «Завершить», «Блок», «В лоток», очередь, история, «＋ экземпляр», «убрать»;
   - лоток Гермеса: заголовок, форма новой задачи, приоритеты;
   - каталог моделей: заголовок, названия полей;
   - статусы: run/wait/blocked/done → «в работе / ожидает / заблокирован / выполнено»;
   - роли: координатор, исполнитель, архитектор, фулстак, сисадмин, дизайнер, UX/UI, приёмщик, рецензент;
   - сообщения нижней строки (MessageBar) и aria-подписи.

   **Генератор:** скрипт `scripts/i18n.mjs` парсит CSV и генерит `src/i18n/translations.ts`
   (типизированный объект). Добавь команду `npm run i18n` в `package.json`. Люди правят
   только CSV; код берёт строки из сгенерированного `translations.ts`.

2. **Контекст языка** — `src/i18n/LanguageProvider.tsx` + хук `useT()`. По умолчанию
   русский. Переключатель RU/EN в `TopBar` (кнопка), выбор сохраняется в `localStorage`.

3. **Замена строк** — во всех UI-компонентах (`src/app/`, `src/ui/`, где есть видимый текст)
   замени хардкод на `t('key')`. Затронутые файлы: `App.tsx`, `SceneView.tsx`, `TopBar.tsx`,
   `WorkerCard.tsx`, `CatalogModal.tsx`, `MessageBar.tsx`, `Modal.tsx`, `DragGhost.tsx`,
   `JournalModal.tsx` и др. (пройди по русским строкам в `src/ui/` и `src/app/`).

4. **Статусы и роли** — там, где рендерится `status`/`role` текстом, бери строку из словаря
   по ключу (например `status.run`), а не храни русский текст в данных.

5. **НЕ переводить** (оставь как есть):
   - сообщения операций `ops.ts` (err/msg) — это доменная логика, зеркалит сервер `journal.py`;
   - названия моделей в `catalog.ts` (имена собственные);
   - комментарии и тесты.

## Тесты

- Тест: переключатель языка меняет видимый текст (например «Завершить» ↔ «Complete»).
- Тест: выбор языка сохраняется в `localStorage` и восстанавливается.
- `npm run build`, `npx vitest run`, `npm run lint` — зелёные.
