# Fix: руки рисуются поверх головы (продолжение issue #2)

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).

## Проблема

В `src/characters/Character.tsx` порядок отрисовки при `layer='all'`:
тело → голова (`ph-head`) → стол → **руки (`ph-arm-a/b`)**.

Руки рисуются ПОСЛЕ головы, поэтому в SVG ложатся поверх неё. Пока персонаж сидит
(голова высоко, руки низко) — не видно. Но в позе сна голова опускается на стол
(`SLEEP_HEAD = translate(2 26) rotate(-28)`) и попадает в зону рук → руки перекрывают голову.

## Что сделать

Поправить z-order так, чтобы **голова рисовалась поверх рук**, а руки — поверх стола.

Сверься с порядком отрисовки в референсе дизайнера: `docs/handoff/Office Orchestrator.dc.html`
(функция `character()` в `<script data-dc-script>`, она же в `docs/handoff/support.js`).
Там видно правильный порядок слоёв (тело / руки / стол / голова). Не изобретай — бери из референса.

## Требования

- Правильный painter-порядок: руки над столом, голова над руками (и в сидячей позе, и в сне).
- Проп `layer` (`'all' | 'body' | 'arms'`) должен продолжать работать для interleaving в сцене.
- Обнови тесты (снапшот/структура: голова после рук в разметке; сон — голова поверх рук).
- `npm run build`, `npx vitest run`, `npm run lint` — зелёные.

## Доклад
Что поменял (порядок слоёв), как сверил с референсом, результат прогона.
