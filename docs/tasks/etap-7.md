# Этап 7: полировка — зум, контр-масштаб, производительность

Ты работаешь в репозитории Prompt Hospital (`/home/hermes/prompt-hospital`).
Прочитай: `docs/handoff/README.md` (раздел «Раскладка сцены», абзац про масштаб и зум).

Работай в `src/app/`, `src/ui/`, `src/scene/` (масштабирование), `src/theme/`.

## Задачи

### 7.1 Реальный зум
Сейчас кнопки −/Вписать/＋ — заглушки. Сделай рабочий зум сцены:
- масштаб сцены меняется (zoom в состоянии UI, НЕ в журнале);
- нижняя граница масштаба **0.55** (дальше — скролл контейнера сцены);
- «Вписать» подгоняет сцену под размер контейнера, но не меньше 0.55.

### 7.2 Контр-масштаб вывесок/конвертов
При отдалении вывески и конверты **контр-масштабируются до ×1.5**, чтобы оставались
читаемыми (по README). Реализуй как обратный множитель `1 / zoom`, ограниченный сверху ×1.5.

### 7.3 Производительность
При большом числе workers (например 20–30 комнат) рендер не должен тормозить:
- профиль: пересборка SVG только при изменении журнала или зума;
- избегай лишних ре-рендеров (мемоизация компонентов комнат);
- если упрёшься в потолок — отметь это в докладе (виртуализация вне scope, но скажи, где узко).

### 7.4 Мелкое
- Убедись, что «Сброс» и «Журнал (JSON-дамп)» работают (этап 4).
- `motion=false` глобально отключает все анимации (проверь, что зум/масштаб не ломают это).

## Требования
- Тесты: зум не опускается ниже 0.55; контр-масштаб вывески ≤ ×1.5; «Вписать» при разных
  размерах контейнера. Производительность — без теста, но с описанием в докладе.
- `npm run build`, `npx vitest run`, `npm run lint` — зелёные.

## Формат доклада
Что сделано (файлы), тесты, результат, где узко по производительности.
