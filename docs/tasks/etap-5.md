## Что сделать

Реализовать **idle-анимации бездельников** — модели в статусе wait/done (кроме Гермеса)
в свободное время делают что-то по своему графику.

## По README (точно)

- Бездельники (wait/done, кроме Гермеса) по графику (~45 с на занятие, со сдвигом по id) выбирают:
  - **гуляет** по коридору перед комнатой (`walkLane 11s` через CSS-переменные `--x0/--y0/--x1/--y1`,
    разворот `face`, шаги `stepA/stepB .45s`);
  - **пьёт кофе** у двери (`sip 4s`, пар `steam 1.6s`);
  - **спит на клавиатуре** (голова на столе, `zfloat` «z z z», слюна `drool`).
- Смена позы — `fadeIn .9s`. Пока гуляет/пьёт кофе — кресло пустое.
- На гуляющего можно кликать и бросать задачи.
- `motion=false` отключает всё (проп уже есть в Character, сохрани совместимость).

## Ключевые keyframes (из README, не выдумывать параметры)

`walkLane` (translate по --x0/--y0/--x1/--y1), `face` (scaleX -1 разворот), `stepA/stepB` (.45s),
`sip` (4s), `steam` (1.6s), `zfloat` (подъём «z z z»), `drool`, `fadeIn` (.9s).

## Требования

- React-компонент `IdleDirector` (или хук), который по статусу worker'а и графику выбирает позу
  и рендерит её поверх/вместо сидячего персонажа. Чистые функции от статуса + времени.
- График детерминированный (по id worker'а), чтобы в тестах можно было предсказать позу.
- Типы строгие, без `any`. Тесты: переключение поз по графику, `motion=false` отключает,
  гулка использует переменные --x0/--y0/--x1/--y1.
