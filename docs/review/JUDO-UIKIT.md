# «МИР ДЗЮДО» — визуальный дизайн: UI-кит и макеты секций

Дата: 2026-09-30. Профиль Каркас CMS: **мини-шоп**, модель **«заявка без оплаты»**.
Основание: `docs/review/JUDO-IA.md` (структура и секции), `docs/review/JUDO-MINISHOP-AUDIT.md`.
Визуальный макет: [`docs/review/judo-uikit/index.html`](judo-uikit/index.html) — открывается
локально в браузере, без сети. Внутри кит компонентов и все 10 секций главной, плюс «Мой заказ»
и mobile sticky-бар.

> Допущение, как и в IA: у задачи в журнале не указан проект, «МИР ДЗЮДО» единственный
> сайт в работе. Фирменных цветов и логотипа заказчика в репозитории нет, поэтому палитра ниже
> предлагается, а не взята из брендбука. Если брендбук есть, меняются только значения токенов
> (§2), а компоненты и секции остаются как есть.

## 1. Концепция: «Додзё»

Премиальность здесь даёт сдержанность, а не золото и градиенты:

- **Хлопок и тушь.** Фон тёплый, цвета небелёного хлопка дзюдоги, текст глубокий, почти чёрный,
  как чёрный пояс. Один акцент, красный хиномару. Его мало: CTA, цена, статус, активный выбор.
- **Ритм татами.** Строгая сетка, тонкие линии-разделители, крупные поля. Скругления минимальные
  (2/6px): так ткань и шов читаются точнее, чем на «мягком» интерфейсе.
- **Фото делают работу.** Макро швов и плетения ткани («Детали решают») и живой зал ИППОН.
  Интерфейс вокруг фото нейтральный и не спорит с ними.
- **Тёмные секции как пауза.** Hero и «Детали решают» инвертированы (фон = цвет текста). Сами
  токены при этом те же, через `color-mix()`, отдельной «тёмной палитры» нет.

Тон копирайтинга спокойный, экспертный, лексика lead-gen: «Добавить в заказ», «Отправить
заявку», «Доступно к заказу».

## 2. Тема: пресет + токены (уровень 1–2, правит владелец)

**Базовый пресет:** `boutique` (премиальная витрина), токены правятся поверх. Если `boutique`
на проверке окажется «декоративным» (засечки, скругления), запасной вариант `minimal`: у него та
же логика поверх.

| Поле `themeSchema` | Значение | Роль |
|---|---|---|
| `colorBg` | `#F5F2EB` | фон: небелёный хлопок |
| `colorBgElev` | `#FFFFFF` | карточки, поля, модалки |
| `colorBgWarm` | `#EBE4D6` | фон чередующихся секций, плашки |
| `colorText` | `#15140F` | основной текст; фон тёмных секций |
| `colorInkSoft` | `#3B372F` | второстепенный текст, подписи |
| `colorMuted` | `#686258` | мета, подсказки, placeholder |
| `colorLine` | `#DCD4C5` | разделители, рамки карточек |
| `colorLineStrong` | `#857B6B` | рамки полей и сегментов (≥ 3:1 для UI) |
| `colorAccent` | `#A3161C` | CTA, цена, активный выбор, фокус |
| `colorOnAccent` | `#FFFFFF` | текст на акценте |
| `radius` | `2px` | кнопки, поля, сегменты |
| `radiusLg` | `6px` | карточки, фото, модалки |
| `space` | `8px` | базовый шаг (сетка 4/8) |
| `shadowCard` | `0 1px 2px rgb(21 20 15 / .06), 0 8px 24px -12px rgb(21 20 15 / .18)` | карточка при hover |
| `fontFamily` | `Inter` (самохостинг, `fontFaces`) | текст |
| `fontHead` | `Inter Tight` (самохостинг, `fontFaces`) | заголовки |
| `headWeight` | `700` | |
| `headLetterSpacing` | `-0.02em` | |

`--c-accent-deep` (hover/pressed) и `--c-price` движок выводит сам. Вручную их не задаём.

**Контраст (WCAG 2.1, проверено расчётом):**

| Пара | Отношение | Норма |
|---|---|---|
| text / bg | 16.5 | AA ✓ |
| inkSoft / bg | 10.6 | AA ✓ |
| muted / bg · warm · elev | 5.4 · 4.8 · 6.0 | AA ✓ |
| accent / bg · elev | 7.0 · 7.8 | AA ✓ |
| onAccent / accent | 7.8 | AA ✓ |
| bg / text (тёмные секции) | 16.5 | AA ✓ |
| lineStrong / bg · elev | 3.7 · 4.2 | 3:1 для UI ✓ |

На тёмных секциях акцентный текст не ставится. Акцент там работает только как заливка кнопки:
белый текст на `accent` даёт 7.8.

**Шрифты.** Inter и Inter Tight (OFL, полная кириллица) загружаются через `fontFaces` и
`theme-fonts-router`, веса 400/500/600 и 600/700, формат WOFF2. Никаких `fonts.googleapis.com`:
это требование реестра ПО. В макете используется системный fallback, потому что файлов шрифтов
в репозитории нет.

**`customCss`:** пусто. Всё ниже выражается токенами или стилями носителя.

## 3. Типографика

Шкала 1.25, mobile → desktop через `clamp()`:

| Токен носителя | Размер | Применение |
|---|---|---|
| display | 40 → 72px, lh 1.0, uppercase не используем | H1 hero |
| h2 | 28 → 44px, lh 1.1 | заголовок секции |
| h3 | 20 → 24px, lh 1.25 | карточки, шаги |
| body | 16 → 17px, lh 1.6, ≤ 68ch | текст |
| small | 14px, lh 1.5 | подписи, мета |
| overline | 12px, 600, `letter-spacing: .14em`, uppercase | надзаголовок секции («01 — Конфигуратор») |

Цены: `font-variant-numeric: tabular-nums`, «от 4 900 ₽» с неразрывным пробелом.

## 4. Компоненты кита

Все компоненты построены на `--c-*`. Цветовых литералов в стилях носителя нет, полутона
получаются через `color-mix()`.

| Компонент | Варианты / состояния | Правила |
|---|---|---|
| **Кнопка** | primary (accent), secondary (контур `line-strong`), ghost (текст), on-dark (светлая на тёмной секции) · hover / active / focus-visible / disabled / loading | высота 48 (sm 40 только на desktop), фокус: кольцо 2px `accent` с отступом 2px |
| **Сегмент-выбор роста** | default / hover / selected / «нет размера» (перечёркнут, `aria-disabled`, остаётся фокусируемым с пояснением) | ячейка ≥ 48×48, сетка `repeat(auto-fill, minmax(56px,1fr))`, это `radiogroup` |
| **Свотч цвета** | белый / синий · selected (кольцо accent) | 44px, подпись текстом рядом: цвет не единственный признак |
| **Статус-бейдж** | «Доступно к заказу» (точка accent) · «Нет размера» (muted) · «Хит» / «Новинка» (контур) | текст + точка, не одна цветная плашка |
| **Карточка товара** | default / hover (`shadowCard`, фото ×1.03) | фото 4:5, название, «от N ₽», бейдж, кнопка «В заказ» (secondary) |
| **Плитка категории** | фото 3:4 с затемнением снизу, название, «N моделей →» | вся плитка одна ссылка |
| **Поле ввода** | default / focus / error (текст ошибки под полем + `aria-describedby`) / disabled | высота 48, рамка `line-strong`, label всегда над полем |
| **Выбор способа связи** | Телефон / WhatsApp / Telegram, radio-плитки | обязателен по аудиту, по умолчанию «Телефон» |
| **Toast** | «Добавлено в заказ» + «Перейти к заказу» | снизу по центру (mobile над sticky-баром), 4 с, `role="status"` |
| **Счётчик «Мой заказ»** | 0 скрыт / 1–99 | бейдж accent на иконке, `aria-label="Мой заказ, 2 позиции"` |
| **Плашка-пояснение** | info (bgWarm + линия accent слева) | «Оплата после подтверждения менеджером» |
| **Аккордеон FAQ** | `<details>/<summary>`, плюс → минус | работает без JS |
| **Шаг** | номер (overline), заголовок, текст | 4 в ряд на desktop, лента на mobile |
| **Sticky-бар (mobile)** | карточка: «Добавить в заказ · 5 400 ₽»; заказ: «Отправить заявку» | высота 64 + safe-area, фон elev, линия сверху |

Движение: 150–200ms `ease-out` для hover и выбора, toast 250ms. Всё отключается при
`prefers-reduced-motion`. Без анимаций страница полностью работоспособна.

## 5. Макеты секций главной

Сетка: контейнер 1240px, 12 колонок, gutter 24; mobile 4 колонки, поля 20px. Вертикальный
ритм секций 96px на desktop и 64px на mobile. Фон чередуется: bg → warm → dark.

### 5.1 «Мой заказ» `/order/`
Desktop 7/5: слева список позиций (фото 64px, название, вариант «рост 150 · белый»,
кол-во −/+, цена, удалить), справа липкая панель: итог «ориентировочно», плашка «Это
предварительная заявка…» (полный текст из аудита), форма, «Отправить заявку». Mobile: список →
форма → sticky «Отправить заявку». Пустое состояние: иллюстрация-пиктограмма пояса, «Пока
пусто», ссылки на 3 категории и конфигуратор.

### 5.2 Карточка товара
Desktop 7/5: галерея (главное фото + превью, последние превью — макро), справа название,
бейдж статуса, цена, сегменты роста, свотчи, «Добавить в заказ», плашка «Оплата после
подтверждения», мини-таблица размера с усадкой. Ниже табы-якоря: Характеристики · Размер · Уход.
Mobile: sticky-бар «Добавить в заказ · цена».

## 6. Разделение работ

| Владелец (админка) | Разработчик (носитель) |
|---|---|
| Значения токенов §2, логотип, фавикон | Шаблоны hero, конфигуратора, «Детали решают» |
| Тексты и фото всех секций, факты, цитата ИППОН | Контент-тип «Деталь» (фото + подпись) |
| Товары, варианты, цены, флаги «хит/новинка» | Сегмент-выбор, свотчи, toast, sticky-бар (островки vanilla JS) |
| Телефон, мессенджеры, адрес (NAP) | Стили носителя на `--c-*` без литералов |
| Шаги «Как заказать», FAQ | Подключение `fontFaces` (Inter, Inter Tight) |

Оговорка для заказчика: hero, конфигуратор и «Детали решают» сделаны шаблонами. Тексты и фото
в них владелец меняет сам, а композицию меняет разработчик. Блочного конструктора в движке нет.

## 8. Вопросы к заказчику

1. Есть ли логотип и фирменные цвета? Если есть, они заменяют §2.
2. Можно ли использовать логотип ИППОН и цитату тренера (письменное согласие)?
3. Реальные характеристики для «Детали решают»: плотность ткани, тип плетения, швы.
4. Фото: есть ли съёмка, или закладываем предметную съёмку в смету.
