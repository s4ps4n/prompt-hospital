# Банк опыта: как решались задачи

Здесь описания реальных работ офиса — по профессиям. Назначение: исполнитель
перед задачей видит, как похожее делали раньше, и не изобретает заново.

## Формат записи

    # Как делали: <краткое название>
    Автор: <кто>. Проект: <где>. Период: <когда>.
    ## Что было (задача)
    ## Что сделал
    ## Что НЕ сработало   ← самое ценное: грабли и тупики
    ## Чем проверял
    ## Что забрать в опыт

Раздел «Что НЕ сработало» обязателен. Успех виден в коде, а причина,
по которой пошли не туда, — только здесь.

## Что уже есть

| файл | профессия | тема |

| `integrator/b24-tochka.md` | интегратор | интеграция банка Точка с Битрикс24 |

| `ops/autopost-reports.md` | сисадмин | автопост и отчёты Каркаса |

## Куда пополнять

По профессии исполнителя, который делал работу:
`arch/`, `design/`, `dev/`, `ops/`, `qa/`, `copy/`, `integrator/`.

## Как это используется

Когда реализуется issue #7: при постановке задачи исполнитель получает
секцию «ОПЫТ ПО ТАКОЙ РАБОТЕ» (свои записи) и «КАК ДЕЛАЛИ В ДРУГИХ
ПРОЕКТАХ» (записи других профессий по той же теме).
