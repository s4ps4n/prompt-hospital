# Как делали: редактор офиса (вёрстка и раскладка)

Автор: Claude Code + Гермес. Проект: `prompt-hospital` (офис).
Период: сентябрь–октябрь 2026.

## Что было (задача)

Офис — изометрическая сцена с «комнатами» исполнителей. Нужно было
доработать интерфейс: показать честно источник данных, поправить счётчики,
уместить всё без прокрутки.

## Что сделал

**1. Плашка источника данных (`SourceBanner`).**

Проблема: офис показывал ДЕМО-данные и выглядел как рабочий пульт —
даже подпись «ДИПСИК-Ф», «ЛИНГ» посчитали выдумкой, а это были реальные
воркеры с обрезанными именами.

Решение: плашка, которая **честно говорит, что на экране**:

    зелёная  «Журнал оркестратора: /hermes/journal» — реальные данные
    красная  «ДЕМО-ДАННЫЕ ...» — связи нет, это макет
    жёлтая   «связь потеряна» — данные были, но устарели

**Ключевой момент:** зелёная включается не по «status: ok» запроса,
а по `store.isRemote()` — то есть **только если журнал реально применён**.
Иначе можно получить «связь есть», а на экране демо.

**2. Счётчики — про задачи, а не про модели.**

В шапке было «в работе / заблокирован / ожидает / выполнено». Считались
**воркеры по статусу**, а читалось как **задачи**. Владелец: «это же задачи?
и цифры пиздят».

Решение: новая функция `taskCounts` — считает `journal.queue`:
задача у воркера → «в работе», задача blocked → «заблокировано»,
остальные → «ожидают». Счётчик «выполнено» **убран**: закрытые задачи
удаляются из очереди, посчитать их честно нельзя. Лучше не показывать
цифру, чем показывать неверную.

**3. Раскладка без прокрутки.**

Владелец: «экран надо скроллить». Решение: счётчики и плашку перенесли
в нижнюю панель, `main` стал ровно `100vh`, средний ряд забирает всю
высоту между шапкой и панелью. Замерено в Chromium: влезает на 1920×1080
и 1366×768 без скролла.

**4. Статика вне авторизации.**

Офис под Basic Auth. Оказалось: `401` на `.js`/`.css` — браузер страницу
открывает, а код не грузит, и показывает старую версию из кэша.
Решение: статику (`/hermes/assets/`, favicon) вывели из-под авторизации,
а API (`/hermes/journal`, `/hermes/op`) — **закрыли** (раньше были открыты
всем). Плюс `Cache-Control: no-cache` на `index.html`.

## Что НЕ сработало

- **Демо-данные выглядели как рабочие.** Долго считали реальных воркеров
  выдумкой: имена в комнатах обрезаются по ширине («ДИПСИК-Ф…»), и это
  похоже на плейсхолдер. Вывод: **демо должно быть подписано явно.**
- **`/hermes/journal` был открыт.** Мы сами сделали счётчики, а API
  к нему оставался публичным. Замечено случайно.
- **Правки держались только локально** — 30 файлов не закоммичены,
  в GitHub лежала версия трёхнедельной давности. Вывод: **работать
  в ветке и пушить сразу.**

## Чем проверял

- 396 тестов (`vitest`), `tsc -b`, `oxlint`;
- headless Chromium (`puppeteer`) — реальная страница, ошибки консоли,
  запросы сети. Так нашли `401` на статике;
- замеры раскладки на 1366×768 и 1920×1080;
- живой боевой адрес с Basic Auth (браузер автоматически шлёт заголовок
  на тот же origin).

## Что забрать в опыт

- **Проверять живой страницей, а не по коду.** Ошибку со статикой
  и раскладкой видно только в браузере.
- **Подписывать демо.** Иначе макет принимают за реальность — и ты,
  и владелец.
- **Не показывать цифру, которую нельзя посчитать честно.** Убранный
  счётчик «выполнено» лучше врущего.
- **Статика и API — разный доступ.** Статику можно отдавать открыто,
  API — только за авторизацией.
