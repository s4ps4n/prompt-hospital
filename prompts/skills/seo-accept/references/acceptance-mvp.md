# Чеклист приёмки MVP

Каждый пункт — да или нет. «Частично» считается за нет.

## Интеграции (§26)

- [ ] Метрика подключается, токен вводится не в открытом виде и не виден в интерфейсе
- [ ] Вебмастер подключается
- [ ] Сбор данных запускается и его состояние видно пользователю
- [ ] Сбой интеграции показан пользователю, а не проглочен

## Аналитика (§26)

- [ ] Связка query → URL видна и её можно открыть в обе стороны
- [ ] Позиции, показы, клики, CTR присутствуют
- [ ] Organic landing pages присутствуют
- [ ] Бизнес-цели и конверсии подтягиваются
- [ ] Периоды 7 / 28 / 90 дней доступны
- [ ] Сравнение с предыдущим периодом есть либо явно помечено как невозможное
- [ ] При нехватке данных выводится INSUFFICIENT DATA

## SEO (§26)

- [ ] Технический аудит выполняется и выдаёт список проблем
- [ ] Обнаруживаются точки роста хотя бы по категориям §9.1–9.5
- [ ] Каждый Finding содержит все поля §17
- [ ] У каждого Finding есть Evidence с числами и периодом
- [ ] Приоритет проставлен и учитывает не только факт ошибки (§19)
- [ ] Уровни приоритета соответствуют §19: CRITICAL / HIGH / MEDIUM / LOW

## Контент (§26)

- [ ] Темы находятся способами §11.1–11.3
- [ ] Кластеризация запросов работает, кластеры осмысленны
- [ ] Контент-план формируется в виде §21 с колонкой причины
- [ ] Content Brief содержит все поля §13
- [ ] У каждой темы указана причина создания и потенциал

## AI (§26)

- [ ] Один провайдер работает
- [ ] Провайдер задаётся конфигурацией, а не кодом
- [ ] AI не изменяет исходные данные

## Отчёты (§26)

- [ ] SEO Report формируется по структуре §20
- [ ] Список Findings формируется
- [ ] Контент-план формируется
- [ ] В отчётах нет токенов и ключей

## Сценарии (§30, §31, §32)

- [ ] «Провести SEO-анализ» проходит от начала до конца
- [ ] «Создать задачу» из Finding даёт все шесть блоков §31
- [ ] «Создать ТЗ» из идеи даёт Content Brief

## Режимы (§25)

- [ ] READ-операции идут без подтверждения
- [ ] Каждая WRITE-операция требует явного подтверждения
- [ ] Изменения логируются

## Границы (§27)

- [ ] Google Search Console отсутствует
- [ ] Google Analytics отсутствует
- [ ] Внешние SEO-сервисы отсутствуют
- [ ] Автоматической публикации нет
- [ ] Автодеплоя нет
- [ ] Массовой генерации страниц нет
