# IdleDirector

SVG-компонент для замены сидячего `Character`. Импорт из `src/animations`.
Передайте `worker`, `catalogEntry`, `lane={{ from: { x, y }, to: { x, y } }}`
и `door={{ x, y }}`. Координаты маршрута и двери относительны месту кресла
(`x`, `y` компонента), в единицах SVG. Их определяет сцена.

Без `timeMs` компонент обновляется по настенным часам, одним timeout до следующей
границы занятия; timeout очищается при размонтировании, отключении motion или
выходе из idle. Для общего времени сцены или тестов передавайте `timeMs` в мс.
`idlePose` — чистая функция; цикл walk → coffee → sleep, по 45 000 мс,
со стабильным хеш-сдвигом id. `w0` и роль координатора исключены.

`motion=false` выключает расписание и CSS-анимации, возвращает сидячий Character.
Системный reduced-motion выключает CSS-анимации; гуляющий остаётся в начале пути.

Прогулка и кофе рисуются стоящим персонажем `Standing` (`src/characters/Standing.tsx`,
перенос `standing()` из docs/handoff): начало координат — ступни, ноги, туловище и
статичная голова, руки; walk — шаги `stepA/stepB` + `bob`, coffee — рука с чашкой (`sip`)
и пар (`steam`). Сон остаётся сидячим `Character`.

Мебель по умолчанию остаётся у кресла, при прогулке/кофе оно пустое.
`furniture=false` позволяет сцене рисовать собственную мебель. Спящая голова
должна рисоваться поверх клавиатуры: при внешней мебели компонент кладётся после стола.

Движущийся SVG target содержит `data-drop={worker.id}`, `data-worker` и принимает
onClick, onPointerDown/Up, onDragOver, onDrop, onKeyDown. Pointer DnD может искать
ближайший `[data-drop]` через elementFromPoint. Операции журнала выполняет хост;
компонент их самостоятельно не вызывает. Click доступен также через Enter/Space.

Подключение (этап 6): `SceneView` берёт общее время из `useIdleClock` (один timeout
до ближайшей границы среди бездельников) и передаёт его как `timeMs`. Маршрут и дверь
считает сцена (`idleRoute` в `src/scene/stations.ts`): прогулка — в коридоре перед
комнатой, кофе — у двери внутри. Сидящий/спящий/пьющий кофе рисуется в слоте комнаты
(за передней стенкой), гуляющий — отдельным объектом сцены с глубиной коридора.
Дизайнеру: согласовать координаты коридора/двери, силуэт спящей головы и
кривые/амплитуды пара и слюны (README задаёт не все эти параметры).

`FLIGHT_MS`/`FLIGHT_EASE` (`flight.ts`) — полёт конверта после drop; таймер и
применение операции по приземлении — в `src/app/useFlights.ts`.
